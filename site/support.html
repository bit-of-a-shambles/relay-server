Support

Setup questions, bug reports, and product feedback are welcome.

Open a GitHub issue

For the fastest public support route, open an issue in the Relay support tracker.

Before you file

Include your iOS app version, macOS version, Relay daemon version, whether you are using Tailscale or local network pairing, and the exact error message you see. Do not include API keys or private source code in a public issue.
